Rock Paper Scissors Game ✊✋✌️

A fun and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. This project helped me practice my front-end web development skills and JavaScript logic.

🚀 Features

Player vs Computer: Play Rock Paper Scissors against the computer.

Automatic Mode: Let the computer play automatically and watch the game results.

Random Computer Moves: The computer randomly selects Rock, Paper, or Scissors.

Score Tracking: Keep track of wins, losses, and ties.

Interactive UI: Simple and user-friendly interface.

Responsive Design: Enjoy the game on different screen sizes.

🛠️ Technologies Used

HTML5

CSS3

JavaScript

🎮 How to Play

Open the game in your browser.

Select Rock, Paper, or Scissors.

The computer randomly chooses its move.

The game compares both moves and displays the result.

In Automatic Mode, the computer plays the game automatically.

Check the score and keep playing!
